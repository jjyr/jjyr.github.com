读书时或许也需要引入一个转化率。有很多书比较有趣但是读过后就容易忘记，或者并没有构成深度的一些思维。
比如最近读的《the price of time》讲了历史上的利率，能记住的就是古代罗马希腊时期因为货币尚未发明，是以物换物，但是货币并非是一个独立的新东西，即使货币未被发明，当时已经有了利率等概念，且很有意思的是每种物品的借贷利率都不一样，希腊时期如果借贷小麦利率是 33 %，惊人的高，但是书里也给了解释，因为小麦等物品是急需的时候才会有人借贷，而且有周期性，缺粮食时可以会饿死人，33%的利率也有人愿意借用，自然更贵，这些人借粮食应急后，等到粮食丰产时的小麦价格下降，再去偿还利息。如此之高的利率正是为了补贴粮食的价格波动。还有一层原因，希腊每次换国王时也正如中国喜欢大赦天下，且希腊贵族比较喜欢慷他人之慨，一换国王就会大赦天下免除民间的借贷，为了抵御这种风险，放贷人自然也会把利率调高点。

本来大赦是为了免除民间负担，却成为了放贷人需要考虑的风险，间接推高了利率，贵族为了提升平民的支持表演的一出戏，却让平民更加的难以渡日，可能平民还会感激吧，我觉得经济学最有意思的就是这种因果的扭曲，有点像是悬疑电影，看到因果后令人感慨。

书中还讲了约翰劳的故事，约翰劳和摄政王是好兄弟，于是借助着权势实验了他的一些金融想法，开办了皇家银行强行发布纸币，并且把利率维持到较低。导致投资泡沫。这里比较有意思的书里解释了低利率导致的资金外逃，因为欧洲的低利率，导致资金转移到高利率国家，当时的法国的钱大笔的流入了高利率的其他欧洲国家，甚至大笔流到了美洲。这是个 17 世纪的故事，但是也可以用来解释 21 世纪的现象。

这本书告诉我们时间有价格，就是利率，利息积累下来复投就是复利，而且人类自古以来就有利率和复利。
最近我想到读书的复利问题，知识的积累也可以产生复利，但是我们读书不是所有东西都能记住。只能记住其中的一部分知识，比如我就只记住上面两个小故事，可能有点用，在有人问希腊时期小麦利率时我可以脱口而出 33%，但是大部分知识是忘掉的，以我的体验只有和自己经历和兴趣有所联系的内容才会被记住。

因此我们读书也有转化率：

```
书 * 兴趣 => 关注到的知识
```

这部分知识已经经过了筛选，属于有用的内容，但是到具体是否会用上（比如算希腊时期的小麦利率），还有一道坎，能否和实际生活体验结合。

```
书 * 兴趣 * 实践  => 产生作用的知识
```

因此读书实际的转化率非常之低。大部分内容根本不会引起关注，而且引起关注的部分我们也很少会去实践。

我产生这个感悟是因为最近读了黄铮的公众号内容，黄铮的文章中引入了很多思考，让我很佩服这个人（不过感谢冥冥之中的命运让我读的比较晚，如果读的早我会在 PDD 上亏更多钱）。黄铮文章中引用了很多罗素幸福之路的内容。让我感觉这个人读书读的很深入，而且会结合自身经验实践。等 PDD 股价涨上去后我会写一篇我的理解，现在写的话难免成为被套牢的幻想，因此等涨上去我再写。

黄铮的文章中对罗素幸福之路的看法，对常识焦虑等看法的抽象和分析，让我意识到虽然我几年前也看过这书，但是我的体会和实践完全为零，我只是看了书而已，内容没有记下，再次阅读时才感到罗素在啪啪打我的脸，意识到罗素书中提到的为了炫耀而读书，如果我读书只是为了评价，以及在书上标记个已读完，那么我读书的原因就是为了炫耀，以及缓解自身焦虑，并非为了兴趣，难怪记不住任何有用的知识。

黄铮把幸福之路的核心总结为尊重常识。我认同这点，往往人的失望、焦虑等等是没有尊重常识，比如为什么牛市中大家都是股神都能夸夸其谈，不会炒股缺敢于加杠杆，等等现象也是不尊重常识。

常识也是需要培养的，我认为能从书中吸取一些常识就是真正的利用书积累了知识，哪怕积累下来的很少，但是这些“常识”才是能产生复利的部分。比如幸福之路说的“尊重常识”，很多人的“常识”中就没有这一条，而我们通过读书，不断的训练积累自己的常识，这些知识才能融入我们的每一次决策和判断。

```
书 * 兴趣 * 实践 * 常识  => 产生复利的知识
```

“常识”从字面意义上理解就是随时可以利用到的知识，举个更实际的佐证，为何这些知识只有成为“常识”才发挥作用。
菲利普费雪写的 《Common stock, Uncommon price》(怎样选择成长股) 书中明确的就有一节 - 在战争时期要敢于买入股票。费雪的道理是战争总是利空货币，因此战争时期把股票换成货币是个很愚蠢的行为，应该在战争时期持续买入股票，等战争结束股市一般都会迅速反弹，此时就能获利。

很可惜，我读过这本书，但是这一章我完全没有印象，因此错过了美伊战争时期的股市。
因为这个知识在我第一次读这本书时没有引起我的兴趣和注意，更没有被我转化为常识。

我举了这么多例子，书中的知识不是我们想象的这么容易被吸收以及使用，读了的书不一定能产生复利，经过层层筛选的“常识”才能产生复利。
其实这点让我想到了现在的 LLM，LLM 吸取了互联网上的一切知识，读过了所有电子化的书，理论上应该很聪明，但是它不知道该如何利用知识。
虽然 LLM 知道所有的计算机知识、编程范式，但是在使用 LLM 写代码时 LLM 并不理解要如何去做，必须由使用者去命令 LLM，LLM 才能利用正确的知识去完成任务。我们现在看到的各种 Coding agent 往往就是在训练环节，或者在 prompt 中去让 LLM 倾向于使用某种更具有适应性的方式去编写代码，也就是 Coding agent 的开发者在告诉 LLM 该如何利用它的知识，而开发者沉淀下来的 prompt, agent harness, 以及训练框架，就像 “常识” 会在 Agent 本身的开发中不断的产生复利。

回到这个公式：

```
书 * 兴趣 * 实践 * 常识  => 产生复利的知识
```

人生有限，不可能读完所有的书，而且罗素在《幸福之路》也说过读书要读感兴趣的书，不要为了炫耀而读，而我的兴趣也有限，因此为了提升“产生复利的知识”，我们只能在“实践”和“常识”环节多花经历，与其花更多的时间读更多的书，不如把读过且感兴趣的内容整理出来，有意识的去实践书中的内容，并从中提取出“常识”。

LLM 掌管知识，而人类知道如何使用知识。
