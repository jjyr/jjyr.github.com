我的观点是封锁顶尖模型在经济上无法持续。

美国政府的想法是只允许美国公司使用顶级的 AI ，以此来保持美国公司的竞争力，但这从经济上行不通。简单来说这个政策会压低 OpenAI 和 Anthropic 的利润，并且“鼓励”厂商使用中国的开放模型。

OpenAI 和 Anthropic 每次发新模型都会变相的上调售价和 Token 消耗，但是这个过程被政府监管打断了。OpenAI 和 Anthropic 在开放模型的竞争下，必须持续投入大量资源保持模型领先，但是价格上又被开放模型锁死，当价格高出太多就会有更多人选择开放模型。因此 OpenAI 和 Anthropic 必须要保证提供的模型服务能力比开放模型高出一截，形成明显的优势，才可以持续把 Token 价格提升。

现在这部分利润无法保证，需要看监管的风向。同时开放模型能力越来越高，一年前我还会担心用不上 ChatGPT 和 Claude code ，现在的话用 Deepseek-v4, glm-5.2 也能达到接近的效果，开放模型已经迈过了可用性的门槛了。在封锁之下如果开放模型能力可以继续提升，会逐渐推动更多厂商转向开放模型，这又会持续减少 OpenAI 和 Anthropic 的利润。

我的判断是考虑 OpenAI 和 Anthropic 都打算在 26、27 年 IPO。AI 限制政策应该只会在短期严格执行，之后会有所松动，以确保两个公司继续提高利润。

长期看 token 的价格总有一个上限，超过上限后模型能力再强也没人愿意付费。除非 OpenAI 和 Anthropic 中的一家能先达到 AGI，并且用智子锁住所有开放 AI 竞争对手的科技水平，这样才能保持垄断性利润。
